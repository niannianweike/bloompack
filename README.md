# 绽放书包（BloomPack）· 小学科学 3D 离线互动书包

把小学科学课堂活动逐课做成**离线可打开的交互式 3D HTML 活页**：孩子打开网页就能直接动手拖拽、实验、观察、比较，把纸面知识变成可互动的立体实验台。

## 快速使用（零安装、全离线）

- **直接打开**：双击总入口 [index.html](index.html)，支持 **3D 书包翻书（精装科学手记 + 3D 实验直接启动）**、**目录总览**、**搜索与接着学**、**小红花进度记录**；也可直接打开 `lessons/` 下任意单课 HTML。
- **全离线运行**：3D 引擎内置在 `vendor/three.min.js`，离线豆包预合成语音内置在 `audio/` 与 `vendor/voice.js`（44 节 100% 纯豆包童声，不回落浏览器机械 TTS），无需外网与后端即可在电脑、平板与手机上流畅打开。
- **局域网访问**：在项目根目录运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000/index.html`。
- **本地造书工作台（Studio）**：运行 `npm run studio`（或 `node studio/server.mjs`）后打开 `http://127.0.0.1:5199`，复制 `studio/.env.example` 为 `studio/.env` 并填入自己的 API Key，即可在本地制作新的 3D 交互活页与配音。

## 目录结构

```text
index.html      3D 书包翻书（极简精装科学手记）+ 目录总览总入口
lessons/        原创 3D 交互活页成品（一上 16 张 + 一下 14 张 + 二上 14 张，共 44 张）
audio/          离线豆包预合成引导语音 MP3 与 manifest.js 索引（2,347 条）
vendor/         three.min.js 与 voice.js（离线豆包语音播放引擎 v2）
studio/         本地造书工作台（用户自带 API Key 本地运行）
tools/          豆包语音同步/接线脚本与 GIF/自动化验收工具
LICENSE         非商用双许可与版权声明
```

## 活页编号规则

`k<年级><册>-<课号>`，例如 `k1a-12` 表示一年级上册第 12 课，`k1b-11` 表示一年级下册第 11 课，`k2a-01` 表示二年级上册第 1 课（`a` = 上册，`b` = 下册）。
